# Huy Portfolio

Minimal personal portfolio for Huy, a frontend developer with full-stack and backend experience.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- HeroUI 3

## Run

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Content

Portfolio content lives in `app/(portfolio)/data/profile.ts`.

Images and static assets live in `public/`.
